# 팀원 최진유 1~3주차 WIL 종합 피드백

## 느낀 점

1~3주차 글을 전체적으로 보면서 HTML, JavaScript, DOM 기초에서 React, CSS, Tailwind CSS, 비동기 통신까지 학습 흐름이 자연스럽게 이어지고 있다는 느낌을 받았다. 단순히 개념을 나열하는 것이 아니라, DOM 조작의 한계에서 React의 필요성으로 연결하고, 일반 CSS의 클래스명 충돌 문제에서 CSS Module의 필요성으로 연결한 점이 좋았다.

## 배운 점

글을 보면서 개념을 단순히 외우는 것보다 각 기술이 왜 필요한지를 연결해서 이해하는 것이 중요하다는 점을 배웠다. 예를 들어 React는 단순히 새로운 문법을 쓰기 위한 도구가 아니라, 기존 DOM 조작 방식의 복잡함을 줄이고 화면을 컴포넌트 단위로 관리하기 위해 사용된다는 점을 다시 생각해볼 수 있었다.

또한 CSS를 사용할 때도 단순히 스타일을 적용하는 것에서 끝나는 것이 아니라 일반 CSS, CSS Module, Tailwind CSS처럼 프로젝트 규모와 상황에 따라 스타일 관리 방식이 달라질 수 있다는 점을 배웠다. 특히 CSS Module이 클래스명 충돌을 막기 위해 사용된다는 설명을 통해 스타일 관리의 중요성을 더 잘 이해할 수 있었다.

## 아쉬운 점

전체적으로 개념 정리의 비중이 크고 직접 구현하면서 겪은 문제 상황이나 오류 해결 과정은 조금 부족하게 느껴졌다. 특히 1~2주차 글은 복습 노트에 가까워서 어떤 코드를 작성했는지 어디서 막혔는지 어떻게 해결했는지가 더 들어가면 WIL로서 더 좋아질 것 같다.

# 팀원 임하영 - 1~3주차 WIL 종합 피드백

## 느낀 점

글에서 학습 과정에서 느낀 감정과 실제 어려움이 솔직하게 드러나서 좋았다. HTML, JavaScript, React, CSS, React Router, Hooks, API 통신까지 내용이 넓게 이어지는데, 단순히 개념만 정리한 것이 아니라 “처음에는 낯설었지만 화면이 변하는 것이 재밌었다”, “AI를 바로 복붙하지 않고 코드를 해석하려고 했다”처럼 직접 해보려는 모습이 좋았다.

## 배운 점

글을 보면서 처음 배우는 개념을 완벽하게 이해하지 못하더라도 직접 화면을 만들고 코드를 수정해보면서 감을 익히는 과정이 중요하다는 점을 배웠다. 특히 AI를 사용하더라도 바로 복사해서 붙여넣는 것이 아니라 코드를 해석하고 하나씩 건드려보며 이해하려는 태도는 정말 배울 점이라고 생각했다.

## 아쉬운 점

전체적으로 학습한 내용은 많지만, 글의 구조가 조금 산만하게 느껴지는 부분이 있었다. 강의에서 들은 내용을 그대로 적은 부분과 본인이 직접 느낀 부분이 섞여 있어서, “개념 정리”, “실습 내용”, “느낀 점”을 구분이 잘 되었다면 더 좋은 글이 되었을 것 같다.

# 팀원 오지훈 - 1~3주차 WIL 종합 피드백

## 느낀 점

1주차부터 3주차까지 쇼핑몰 사이트를 직접 발전시켜 나가는 과정이 잘 드러났다. 처음에는 웹 개발에 필요한 자료를 찾아보고 쇼핑몰 페이지의 디자인을 만드는 것에서 시작해, 2주차에는 Tailwind CSS, React Hooks, mockData를 이용한 데이터 출력까지 확장되었고, 3주차에는 API 통신과 AdminPage 구현까지 이어졌다.

## 배운 점

글을 통해 프로젝트를 단계적으로 발전시키는 방식이 중요하다는 점을 배웠다. 처음부터 완성된 기능을 만들려고 하기보다 1주차에는 화면 디자인을 만들고, 2주차에는 mockData로 데이터를 출력하고, 3주차에는 fetch와 AdminPage를 추가하는 식으로 조금씩 확장해가는 모습이 좋았다.

## 아쉬운 점

전체적으로 글의 흐름은 좋지만 1주차 글은 내용이 다소 짧아서 무엇을 학습했고 어떤 방식으로 쇼핑몰 페이지를 만들었는지가 조금 부족하게 느껴졌다. 2주차 글에서는 Tailwind CSS와 바닐라 CSS의 차이를 설명하려고 한 점은 좋지만 실제 코드 예시나 비교 설명이 조금 더 구체적이면 이해하기 쉬웠을 것 같다.
