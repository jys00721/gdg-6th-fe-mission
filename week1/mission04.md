# React 컴포넌트 복습 정리

## 1. 컴포넌트란?

컴포넌트는 React에서 화면을 구성하는 독립적인 UI 조각이다.

웹페이지 전체를 한 번에 만드는 것이 아니라, 역할별로 작은 부분으로 나누어 만든다.

예를 들어 쇼핑몰 페이지는 다음처럼 나눌 수 있다.

```text
App
├─ Navbar
├─ Content
└─ Footer
```

각 컴포넌트는 자기 역할에 맞는 화면과 기능을 담당한다.

---

## 2. 왜 컴포넌트로 나누어야 할까?

컴포넌트로 나누면 코드 관리가 쉬워진다.

하나의 파일에 모든 코드를 작성하면 페이지가 커질수록 복잡해지고 수정하기 어려워진다.  
하지만 컴포넌트로 나누면 각 부분이 독립적으로 관리되기 때문에 유지보수가 쉬워진다.

### 컴포넌트로 나누는 이유

- 코드 구조가 깔끔해진다.
- 같은 UI를 여러 곳에서 재사용할 수 있다.
- 수정할 부분을 찾기 쉽다.
- 각 컴포넌트가 하나의 역할만 담당하므로 이해하기 쉽다.
- 협업할 때 역할을 나누기 좋다.

---

## 3. 어떤 기준으로 컴포넌트를 나누면 좋을까?

컴포넌트는 역할과 재사용 가능성을 기준으로 나누는 것이 좋다.

### 1) 역할이 다르면 나누기

서로 하는 일이 다르면 다른 컴포넌트로 분리한다.

예를 들어 상단 메뉴, 검색창, 상품 목록, 하단 영역은 각각 역할이 다르므로 나누는 것이 좋다.

```text
Navbar
SearchBar
ProductList
Footer
```

---

### 2) 반복되는 UI는 나누기

같은 모양이 여러 번 반복된다면 컴포넌트로 만드는 것이 좋다.

예를 들어 상품 카드가 여러 개 반복된다면 `ProductItem` 컴포넌트로 만들 수 있다.

```jsx
<ProductItem />
<ProductItem />
<ProductItem />
```

---

### 3) 너무 길어진 코드는 나누기

하나의 컴포넌트가 너무 길어지면 읽기 어렵다.  
이럴 때는 내부의 일부 영역을 작은 컴포넌트로 분리하면 좋다.

예를 들어 `ProductList` 안에 상품 하나를 나타내는 부분이 길다면 `ProductItem`으로 분리한다.
