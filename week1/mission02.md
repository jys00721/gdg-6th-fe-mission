# HTML5

## 1. HTML5 기본 문법

HTML은 웹페이지의 구조를 만드는 언어이다.  
태그를 사용해서 제목, 문단, 이미지, 링크, 버튼, 입력창 등을 표현한다.

HTML 문서는 보통 다음과 같은 기본 구조를 가진다.

```html
<!DOCTYPE html>
<html>
  <head>
    <title>페이지 제목</title>
  </head>
  <body>
    화면에 보이는 내용
  </body>
</html>
```

- `<!DOCTYPE html>`: HTML5 문서임을 알려줌
- `<html>`: HTML 문서 전체를 감싸는 태그
- `<head>`: 페이지 정보, 제목, 설정 등이 들어가는 부분
- `<body>`: 실제 화면에 보이는 내용이 들어가는 부분

---

## 2. 시맨틱 요소와 검색 엔진

시맨틱 요소는 태그 이름만 봐도 의미를 알 수 있는 태그이다.

```html
<header>상단 영역</header>
<nav>메뉴 영역</nav>
<main>주요 내용</main>
<section>구역</section>
<article>독립적인 글</article>
<footer>하단 영역</footer>
```

시맨틱 태그를 사용하면 코드 구조가 명확해지고 검색 엔진이 웹페이지의 내용을 더 잘 이해할 수 있다.  
따라서 검색 엔진 최적화에도 도움이 된다.

---

## 3. 웹페이지를 구성하는 기본 태그

웹페이지는 여러 기본 태그를 조합해서 만든다.

자주 사용하는 기본 태그는 다음과 같다.

| 태그            | 역할      |
| --------------- | --------- |
| `<h1>` ~ `<h6>` | 제목      |
| `<p>`           | 문단      |
| `<img>`         | 이미지    |
| `<a>`           | 링크      |
| `<button>`      | 버튼      |
| `<input>`       | 입력창    |
| `<div>`         | 영역 구분 |

---

## 4. 텍스트 관련 태그

텍스트를 표현할 때는 상황에 맞는 태그를 사용해야 한다.

```html
<h1>제목</h1>
<p>본문 내용입니다.</p>
<strong>중요한 내용</strong>
<em>강조할 내용</em>
```

| 태그            | 의미        |
| --------------- | ----------- |
| `<h1>` ~ `<h6>` | 제목        |
| `<p>`           | 일반 문단   |
| `<strong>`      | 중요한 내용 |
| `<em>`          | 강조할 내용 |
| `<br>`          | 줄바꿈      |
| `<hr>`          | 구분선      |

---

## 5. HTML의 핵심 개념인 Hyperlink

HTML에서 중요한 기능 중 하나는 하이퍼링크이다.  
하이퍼링크는 다른 페이지나 웹사이트로 이동할 수 있게 해주는 기능이다.

링크는 `<a>` 태그로 만든다.

```html
<a href="https://example.com">사이트로 이동</a>
```

- `<a>`: 링크를 만드는 태그
- `href`: 이동할 주소를 지정하는 속성
- 태그 사이의 내용: 사용자가 클릭하는 부분

---

## 정리

HTML은 웹페이지의 뼈대를 만드는 언어이다.
태그를 사용해서 제목, 문단, 이미지, 버튼, 입력창, 링크 등을 구성한다.  
특히 시맨틱 태그를 사용하면 코드의 의미가 명확해지고, 검색 엔진과 사용자 모두에게 더 좋은 웹페이지를 만들 수 있다.

# 자바스크립트

## 1. 자바스크립트의 기본 문법

자바스크립트는 웹페이지에 동작을 추가하는 프로그래밍 언어이다.  
HTML이 구조를 만들고 CSS가 디자인을 담당한다면, 자바스크립트는 버튼 클릭, 입력값 처리, 화면 변경 같은 기능을 담당한다.

```js
console.log("Hello World");
```

`console.log()`는 값을 콘솔창에 출력할 때 사용한다.  
코드가 잘 실행되는지 확인할 때 자주 사용한다.

---

## 2. 데이터 타입과 변수

변수는 값을 저장하는 공간이다.  
자바스크립트에서는 `let`, `const`, `var`를 사용해 변수를 만든다.

```js
let name = "철수";
const age = 20;
```

- `let`: 값이 바뀔 수 있는 변수
- `const`: 한 번 정하면 바꿀 수 없는 변수
- `var`: 예전 방식의 변수 선언

자주 사용하는 데이터 타입은 다음과 같다.

| 타입      | 예시               | 설명                        |
| --------- | ------------------ | --------------------------- |
| Number    | `10`, `3.14`       | 숫자                        |
| String    | `"hello"`          | 문자열                      |
| Boolean   | `true`, `false`    | 참/거짓                     |
| Object    | `{ name: "철수" }` | 여러 값을 묶은 데이터       |
| Array     | `[1, 2, 3]`        | 여러 값을 순서대로 저장     |
| undefined | `undefined`        | 값이 아직 없음              |
| null      | `null`             | 값이 없음을 의도적으로 표현 |

---

## 3. 연산자

연산자는 값을 계산하거나 비교할 때 사용한다.

```js
let a = 10;
let b = 3;

console.log(a + b);
console.log(a > b);
```

대표적인 연산자는 다음과 같다.

| 종류        | 예시                    | 설명    |
| ----------- | ----------------------- | ------- | ------ | --------- |
| 산술 연산자 | `+`, `-`, `*`, `/`, `%` | 계산    |
| 비교 연산자 | `>`, `<`, `===`, `!==`  | 값 비교 |
| 논리 연산자 | `&&`, `                 |         | `, `!` | 조건 조합 |
| 대입 연산자 | `=`, `+=`, `-=`         | 값 저장 |

특히 `===`는 값과 타입을 모두 비교하기 때문에 자바스크립트에서는 `==`보다 `===`를 사용하는 것이 좋다.

---

## 4. 제어문

제어문은 조건에 따라 코드를 실행하거나 반복할 때 사용한다.

조건문은 `if`를 사용한다.

```js
let score = 80;

if (score >= 60) {
  console.log("합격");
} else {
  console.log("불합격");
}
```

반복문은 `for`를 사용한다.

```js
for (let i = 0; i < 5; i++) {
  console.log(i);
}
```

`if`는 조건에 따라 실행할 코드를 선택하고, `for`는 같은 코드를 여러 번 반복할 때 사용한다.

---

## 정리

자바스크립트는 웹페이지에 기능을 추가하는 언어이다.  
변수에는 값을 저장하고, 데이터 타입은 값의 종류를 나타낸다.  
연산자는 계산과 비교에 사용하며, 제어문은 조건 처리와 반복 작업에 사용한다.
